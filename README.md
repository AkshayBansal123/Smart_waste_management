# Developed an app that can classify wastes and on the basis of classification can direct the course of disposal.  <br/>
Function : upload an image and the ML algo will tell the class of the waste and the appropriate course of action.   <br/>
Usecase : can be integrated at the ground level using <br/>
   \tcameras and sensors equipped bins<br/>
   gps enabled tracking<br/>
   waste images are captured and classified <br/>
   the robots receive signals regarding the position of the bin <br/>
   Route optimisation and close monitoring
   <br/>
Tech : html , css and js for frontend <br/>
      flask for backend <br/>
      numpy for image processing <br/>
      tensorflow keras for image processing <br/>
